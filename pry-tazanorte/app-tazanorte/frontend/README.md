# TazaNorte · Frontend

Frontend de **TazaNorte** (cafetería y fidelización) construido con Angular 22, Signals, PrimeNG 22 (tema Aura) y Tailwind CSS 4.

El backend Express correspondiente expone su API en `http://localhost:4000/api`.

## Comandos

```bash
npm ci          # instala dependencias
npm start       # servidor de desarrollo en http://localhost:4200
npm run build   # compilación de producción
npm test -- --watch=false   # pruebas unitarias
```
